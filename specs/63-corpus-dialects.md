## AC — automatic classification (user 2026-10-14: *"You ought not to manually classify everything it should be automatic"*)
Labels (dialect, region, surzhyk/contact, usage/register, archaism, POS) are produced by code from what the sources already say, never by hand-curated word lists. Hand lists survive only as test fixtures and seeds for evaluation.
- **AC-1** Label extraction: every ingested dictionary witness (Грінченко, Уманець–Спілка, Ніковський, ЕУМ, dialect dictionaries, uk.wiktionary, r2u) is parsed for its own label abbreviations («діал.», «розм.», «заст.», «рідко», «пол.», «рос.», «гал.», «волин.», region names…) through one abbreviation table per source (taken from the source's list of abbreviations, cited) → claims {label, source, verbatim quote, locator}. No label without such a quote.
- **AC-2** Region → dialect group mapping is computed from a cited gazetteer (research/04 areas; place/region name → group), not assigned per word.
- **AC-3** Surzhyk/contact: computed from r2u Russian→Ukrainian pairs + VESUM/pymorphy3-ru membership (form ∉ VESUM ∧ ∈ ru dictionary ∧ r2u gives a Ukrainian equivalent) with the r2u quote; no manual lists.
- **AC-4** Phonetic dialect markers stay rule-based (DIALECT_RULES) but rule rows are generated from the dialectology sources' feature tables where machine-readable; every lemma's labels are recomputed on each build.
- **AC-5** Report: per label type coverage before/after, precision on the hand fixtures (old manual lists), in analysis/auto-classification.md.

## DP — dialect pronoun variants (user 2026-10-14: *"Variation тамтой and others from the effect should also be derived and shown and maybe there's an evidence it's a feature for Ukrainian Western dialects?"*)

- **DP-4** UI: the standard lemma card shows a «діалектні варіанти» block (variant, paradigm, region, evidence); variant forms have their own /f pages; corpus tokens of variants link.

## FD — dialect attribution on the form page (user 2026-10-14, screenshot /f/йому: *"For a form (of a word) page it should be also specified to which dialect it possible leads"*)
- **FD-1** The form page (/f/:form) shows a «діалект» block: every dialect marker rule (DIALECT_RULES, DIALECT_BOOK_RULES) that fires on this spelling, every lexical/variant dialect claim (AC, DP) for it, each with group/region, rule id, evidence [Q] + locator and the earliest dating of that feature; computed automatically, no per-form labels.
- **FD-2** Witness geography as separate evidence: regions of the witnesses in which this spelling occurs (from witness metadata), shown as "засвідчено в: …", never merged into the dialect label unless a rule/claim supports it.
- **FD-3** When nothing fires: «діалектних ознак не виявлено (норма / невідомо)» with the list of rules checked — never an empty block; every group/rule/source chip is clickable (BL-16).
- **FD-4** (user: *"To the whole class of the forms"*) Attribution is per form class, not only per spelling: the paradigm cell (lemma + grammemes, e.g. він Dat.Sg) groups all its attested and derived variants (йому / єму / ему / йиму / ёму …, DP variants), and the block shows a table variant → dialect group(s) → evidence → earliest dating → frequency, with the current spelling highlighted; the same table appears on every member's /f page and on the lemma card per cell.
- **FD-5** Feature class: for each firing rule, «інші форми з цією ознакою» — the lexicon forms on which the same rule fires (count + top examples by f, link to a filtered list), so the class of forms sharing a dialect feature is navigable.

## DX — deictic adverbs and particle compounds (user 2026-10-14: *"Ондо (он там), тамки and the whole class of the forms which lead to this effect should also be categorized and linked to a dialectical feature"* · *"«отуточки», «онтамека», «осьтамека», «озьдо»"* · *"Де всі ці слова в літературній мові…"*)
- **DX-1** Research (research/32 §DX): the deictic word-formation class — base (там, тут, ту, он, ось, от, се, то, ге…) + deictic particles/suffixes (-ки, -ка/-ека/-ечки, -о/-до/-дьо/-зьдо, -й, -во, он-/ось-/от-/о- prefixes, reduplication тамтам-) — each affix with source, verbatim quote, locator and the dialect group/region the source names (ЕУМ, Жилко, Бевзенко, АУМ, Грінченко, dialect dictionaries, СУМ-11 labels «діал.», «розм.»). Every claim evidenced; unevidenced = unknown.
- **DX-2** Segmentation by rule: any token is analysed as base + particle chain (ондо = он + до; онтамека = он + там + ека; осьтамека = ось + там + ека; отуточки = о + тут + очки; озьдо = о + зьдо …); a token is accepted only if every segment is a sourced affix; the result links to the base lemma and to each affix's dialect feature.
- **DX-3** Literary equivalent: each variant shows its standard Ukrainian counterpart (ондо → он там / онде; тамки → там) with the dictionary that gives it (СУМ-11, ВЕСУМ, Грінченко), or «у літературній мові не зафіксовано» + where it is recorded; FD-4/FD-5 class tables include these forms.
